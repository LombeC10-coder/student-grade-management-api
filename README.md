# Student Grade Management APIA Java Spring Boot backend project for managing students, modules, registrations and grades.This project was developed as part of a university software engineering module and demonstrates backend development, object-oriented programming, REST API structure, relational database design and automated testing.## Features- Student, module, registration and grade domain models- REST controller for grade-related operations- Repository layer for database access- Custom exceptions for missing grades and registrations- SQL schema for relational data storage- Unit and controller tests## Technologies Used- Java- Spring Boot- Maven- SQL- JUnit- Git## Skills Demonstrated- Object-oriented programming- Backend API development- Domain modelling- Repository pattern- Exception handling- Database schema design- Unit testing and controller testing## How to Run Tests```bash./mvnw test
